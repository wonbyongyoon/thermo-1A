물리화학의 부호 규약: \(\Delta U = q + w\)

물리화학 (Ball)공학 열역학(일부 교재)
1법칙\(\Delta U = q + w\)\(\Delta U = Q - W\)
일의 기준\(w\): 계가 받은 일\(W\): 계가 한 일
팽창 일\(w = -\int P_{ext}\,dV\)\(W = +\int P\,dV\)
관계\(q = Q,\quad w = -W\) → 같은 물리 현상, 부호 표현만 다름

상태함수와 경로함수

상태함수 \(U, H, T, P, V\): 현재 상태만으로 값이 결정. 미소변화는 완전미분(exact differential) \(dU\)이고 $$\Delta U = \int_1^2 dU = U_2 - U_1,\qquad \oint dU = 0$$

경로함수 \(q, w\): 과정(경로)에 따라 값이 달라짐. 미소량은 불완전미분으로 \(\dbar q,\ \dbar w\)로 구별하여 씁니다 (교재에 따라 \(\delta q\)). $$dU = \dbar q + \dbar w,\qquad \int_1^2 \dbar q = q \ (\ne q_2 - q_1)$$

압력-부피 일: \(\dbar w = -P_{ext}\,dV\). 가역과정에서는 \(P_{ext} = P\) (계의 압력)이므로 \(w_{rev} = -\int P\,dV\) = P–V 선도에서 경로 아래 면적(부호 포함).

가역 과정: 매 순간 계가 평형에 무한히 가깝게 유지되며, 무한소 변화로 방향을 되돌릴 수 있는 과정. 경로가 P–V 선도에 선으로 그려집니다.
비가역 과정: 유한한 압력차로 일어나는 실제 과정. 중간 상태의 계 압력은 정의되지 않으므로, 일은 외부압력으로 계산합니다: \(w = -P_{ext}\Delta V\).

등엔탈피선: T 대 P

등엔탈피임을 보이기와 \(\mu_{JT}\)

단열된 관에서 다공성 마개를 지나 기체 \(n\) mol이 \(P_1,V_1\)에서 \(P_2,V_2\)로 이동. \(q = 0\).

왼쪽 피스톤이 기체에 하는 일 \(+P_1V_1\), 오른쪽에서 기체가 하는 일 \(-P_2V_2\):

$$w = P_1V_1 - P_2V_2,\qquad \Delta U = U_2 - U_1 = q + w = P_1V_1 - P_2V_2$$ $$U_2 + P_2V_2 = U_1 + P_1V_1 \;\Rightarrow\; H_2 = H_1 \quad(\text{등엔탈피})$$

줄-톰슨 계수 (Joule-Thomson coefficient):

$$\mu_{JT} \equiv \left(\frac{\partial T}{\partial P}\right)_H$$

팽창에서 \(dP<0\) 이므로 \(\mu_{JT}>0\)이면 냉각, \(\mu_{JT}<0\)이면 가열.

\(H(T,P)\)의 전미분 \(dH = C_P\,dT + (\partial H/\partial P)_T\,dP\)에서 \(dH = 0\)으로 두면

$$\left(\frac{\partial H}{\partial P}\right)_T = -C_P\,\mu_{JT}\qquad(\text{순환 규칙과 같은 결과})$$

이상기체: \(H = H(T)\) → \((\partial H/\partial P)_T = 0\) → \(\mu_{JT} = 0\) (온도 변화 없음).

반데르발스 기체의 저압 근사:

$$\mu_{JT} \approx \frac{1}{C_{P,m}}\left(\frac{2a}{RT} - b\right),\qquad T_{inv} = \frac{2a}{Rb}$$

인력(a) 항이 우세한 저온에서는 냉각, 반발(b) 항이 우세한 고온에서는 가열. 이 근사식의 역전온도는 실측보다 큽니다 (예: N₂ 실측 약 621 K).

연습문제 (무작위 출제)

R = 8.314 J mol⁻¹ K⁻¹, 1 L·bar = 100 J. 답은 J 단위, 부호 포함 (허용오차 ±2%).
